# Mako Blade

Blade templating engine for Mako Framework.

## Installation

Configure composer.json:

	"require": {
		...
		"makopro/blade": "*"
	,
    "repositories": [
        {
            "type": "vcs",
            "url": "https://github.com/mako-pro/blade"
        }
    ],
    "minimum-stability": "dev",
	"prefer-stable": true
